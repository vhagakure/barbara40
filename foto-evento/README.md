# Foto della serata

Carica qui le foto selezionate in formato JPG, PNG, WebP o AVIF. I nomi dei file determinano l’ordine, per esempio `001.jpg`, `002.jpg`, `003.jpg`.

1. Nel repository su GitHub, apri `foto-evento` e scegli **Add file → Upload files**.
2. Trascina le immagini nella pagina e salva su `main`. Se lavori da un ramo separato, uniscilo a `main`.
3. In **Actions → Aggiorna l’album** puoi vedere lo stato del caricamento. Quando è completato, le nuove foto compaiono nella vista **Dopo la festa** dal 23 dicembre, ora italiana. Una pagina già aperta si aggiorna entro cinque minuti.

Il flusso copia i file nel bucket privato del sito. Ricaricare lo stesso nome sostituisce il file nell’album. Per rimuovere una foto già pubblicata, elimina anche il file corrispondente nel bucket R2.

Per aggiungere il filmato di apertura, usa `hero.mp4` (consigliato, H.264) oppure `hero.webm`. Se ci sono entrambi, l’album usa l’MP4. Il video compare sopra le foto, con riproduzione a richiesta. Da browser GitHub accetta fino a 25 MiB per file. Se le foto dell’iPhone sono in formato HEIC, esportale prima come JPG.

In questo repository pubblico le foto caricate sono visibili direttamente su GitHub dal momento del commit. L’album dell’invito le mostra dopo la festa.
